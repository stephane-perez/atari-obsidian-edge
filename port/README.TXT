Obsidian Edge @VERSION@
===================

Disk management utility for Atari ST/STE/TT/Falcon (FAT12/FAT16),
derived from Diamond Edge 2.57 (GPL release by Roger Burrows).
Source code: https://github.com/stephane-perez/atari-obsidian-edge

THIS IS A TEST BUILD.  It is the Diamond Edge 2.57 source code, unchanged
in function, rebuilt with a modern compiler (GCC) instead of Lattice C.
The programs still call themselves "Diamond Edge v2.57".
Back up your disks before using it.

What has been tested
--------------------
Only in the Hatari emulator, with EmuTOS 1.3: INSTALL.PRG installs Diamond
Edge (ST, monochrome), EDGE.PRG starts and shows its menus (ST monochrome,
and STE in medium resolution with the colour icons).  NO DISK FUNCTION HAS
BEEN TESTED YET, Diamond Mirror has not been tried from the AUTO folder,
and nothing has been tried on a real machine.

How to install
--------------
1. Copy or move DMIRROR.PRG to C:\AUTO.
3. Double click on EDGE.PRG to run Obsidian Edge
