Obsidian Edge @VERSION@
===================

Disk management utility for Atari ST/STE/TT/Falcon (FAT12/FAT16),
derived from Diamond Edge 2.57 (GPL release by Roger Burrows).
Source code: https://github.com/stephane-perez/atari-obsidian-edge

THIS IS A TEST BUILD.  It is the Diamond Edge 2.57 source code, unchanged
in function, rebuilt with a modern compiler (GCC) instead of Lattice C.
The programs still call themselves "Diamond Edge v2.57".
Back up your disks before using it.

What has been tested
--------------------
Only in the Hatari emulator (ST, 4 MB, monochrome), with EmuTOS 1.3:
INSTALL.PRG installs Diamond Edge, and EDGE.PRG starts and shows its
menus.  NO DISK FUNCTION HAS BEEN TESTED YET, Diamond Mirror has not been
tried from the AUTO folder, and nothing has been tried on a real machine.

How to install
--------------
1. Double-click on INSTALL.PRG.
2. Enter your name, select the drive to install on, and choose whether
   to install Diamond Mirror in the AUTO folder of your boot drive.
   You do not need a serial number or a registration code.
3. Click on 'Install'.  The program is installed in X:\EDGE.
